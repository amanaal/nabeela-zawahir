# Nabeela Zawahir Portfolio

Fashion designer, visual merchandiser and content creator.

## Publish on GitHub Pages

1. Create a new public repository on GitHub (for example `nabeela-portfolio`).
2. Upload everything in this folder, keeping `index.html` and the `media` folder at the top level.
3. In the repository, go to **Settings > Pages**.
4. Under **Build and deployment**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. After a minute or two the site will be live at `https://amanaal.github.io/nabeela-zawahir/`.

To use the address `https://<your-username>.github.io/` instead, name the repository `<your-username>.github.io`.
